## 🌐 How to Deploy

### Option 1: GitHub Pages
1. Initialize a git repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Robiul's portfolio"
   ```
2. Push to your GitHub repository (e.g., `robiul-portfolio`).
3. In GitHub, go to **Settings > Pages**.
4. Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
5. Your website will be live at `https://<username>.github.io/<repo-name>/`. All asset paths use relative links (`./assets/...`), so it works seamlessly on subpaths!

### Option 2: Netlify
1. Log in to [Netlify](https://www.netlify.com/).
2. Drag and drop the `robiul` folder directly into Netlify Drop, or connect your GitHub repository.
3. No build command required. Publish directory: `.` (or leave empty).

### Option 3: Vercel
1. Log in to [Vercel](https://vercel.com/).
2. Import the Git repository or deploy via `vercel cli`.
3. Framework Preset: **Other** (Static HTML).
